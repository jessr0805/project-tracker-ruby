# Project Tracker (RUBY)

A Ruby-based Project Tracker for people who want to keep track of their projects, practice Ruby, or check out what basic Ruby code looks like.

## Cool Features

* **Add Projects**
* **View Active Projects**
* **Complete Projects**
* **Separate Active and Completed Projects**
* **Interactive Terminal Menu**

## How to Run It

Ensure Ruby is installed
If it isn't visit the
[Official Ruby Installer Link](https://www.ruby-lang.org/en/downloads/)

To run the project tracker directly in the terminal,

* Clone the repository
* Navigate to the repository in your terminal
* Run

  ```bash
  ruby main.rb
  ```
